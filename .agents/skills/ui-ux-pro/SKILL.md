# UI/UX Pro Design System (Linear & Vercel Inspired)

## Core Principles
1. **Zero AI Slop**: Avoid cheesy glowing gradients, aggressive neon borders, 3D holographic blobs, and noisy background graphics.
2. **Clean Surface Hierarchy**: Use subtle neutral backgrounds (`#09090b` / `#0c0c0e`), flat dark cards (`#18181b`), and crisp subtle borders (`#27272a`).
3. **Typography**: Clean, readable typography using `Inter` or `-apple-system`. Crisp font sizing (`text-xs` for labels, `text-sm` for body, `text-lg` for card titles, `text-2xl` for page headers).
4. **Subtle Accents**: Use refined indigo (`#5e6ad2` / `indigo-500`) or crisp monochrome accents instead of vibrant rainbow gradients.
5. **Micro-Details**: High information density, clean tabular layouts, subtle status badges (`bg-zinc-800 text-zinc-300`), and smooth 150ms transitions.
